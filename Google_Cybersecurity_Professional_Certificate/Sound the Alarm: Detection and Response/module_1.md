# Module 1: Introduction to detection and incident response
## Overview
This module will help me understand the incident response lifecycle and practice using tools to detect and respond to cybersecurity incidents.


## Learning Objectives
-  Learn about the **incident response lifecycle** and how incident response teams work together.
-  Learn about the types of tools used in detection and response, including documentation.
-  Given your own incident handler's journal that you'll use during your investigations.
-  Apply your knowledge and networking in Linux to monitor and analyze network traffic using packet sniffers like Wireshark and tcpdump
-  Familiar with the common processes and procedures used during incident detection and response.
-  Learn how to interpret logs and alerts.

## Key Concepts I Learned
According to NIST, an **incident** is "an occurrence that actually or imminently jeopardizes, without lawful authority, the confidentiality, integrity, or availability of information or an information system;

An **event** is an observable occurrence on a network, system, or device.

Five W's of an incident: 
- **who** triggered the incident,
- **what** happened,
- **when** the incident took place,
- **where** the incident took place, and
-  **why** the incident occurred.

**incident handler's journal**, which is a form of documentation used in incident response.
