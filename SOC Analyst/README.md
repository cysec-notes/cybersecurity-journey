# SOC Analyst
This repository documents my journey toward becoming a Security Operations Center (SOC) Analyst through hands-on labs, practical investigations, and continuous learning. The focus is on developing real-world skills in threat detection, log analysis, incident investigation, and security monitoring.


## About the SOC Analyst Role
A SOC Analyst is responsible for monitoring, detecting, investigating, and responding to cybersecurity threats. They analyze security events from multiple data sources, identify malicious activity, and help protect an organization's infrastructure.

Core responsibilities include:
- Monitoring security alerts and events
- Investigating suspicious activities
- Analyzing system, network, and security logs
- Detecting indicators of compromise (IOCs)
- Supporting incident response and containment
- Escalating confirmed security incidents
- Creating documentation and investigation reports
